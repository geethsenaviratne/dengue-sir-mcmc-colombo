When should mosquito control start?

If mosquito control had cut transmission by 20% for the rest of the season, starting 4 weeks before the peak, the 2017 peak would have been 37.0% lower (95% credible interval 31.0–41.1%) and come 5 weeks earlier.

How to use

  1. Set how strong the control is, how early it starts and how long it lasts. The results update at once.
  2. Press Start to watch weeks 12 to 42 of 2017 unfold, Pause to stop, and Reset to go back to the reference scenario.
  3. Hover over the chart, or select it and use the arrow keys, to read any week.

Try this

Set a 10% cut starting 8 weeks before the peak, and note the peak reduction. Then set a 40% cut starting in the peak week. The weak, early campaign lowers the peak far more than the strong, late one.

Reading the results

Peak reduction is how much lower the worst week would be. Peak timing is how many weeks earlier or later it comes. Cases averted is the share of reported cases in weeks 12 to 42 that would not have happened. Each is the median of 200 model runs, with a 95% credible interval. When the cut is larger than the critical cut, cases stop growing as soon as control begins.

About the model

The model splits Colombo's 2.48 million people into susceptible, infected and recovered groups (an SIR model). People recover after about 6.5 days. The transmission rate drops smoothly in early August, when the 2017 epidemic collapsed. The equations are solved with a fourth-order Runge–Kutta method, 10 steps per week.

The transmission rate, the size and timing of the August drop, the starting number of infections and the background cases were fitted to the reported weekly cases with a Metropolis MCMC sampler. This page runs the model on 200 of the resulting parameter sets, so every result carries its uncertainty.

Mosquito control multiplies the transmission rate by one minus the cut while it runs, switched on and off over half a week. The start week is set separately for each parameter set, from that run's own peak without control.

Limitations

  • Starting "4 weeks before the peak" uses hindsight. In a real season the peak week is not known in advance.
  • The cut is an idealised, constant reduction. Real campaigns vary in strength.
  • Mosquitoes are not modelled directly, and the model covers one district and one season.
  • The early-August drop is assumed to happen in every scenario.
